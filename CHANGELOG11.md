# codelib 0.1.10 · Alpha

13 ноября 2026 · сборка 11.

## Продолжение CHANGELOG1 §10
- Переведены ещё **3 полных раздела / 11 уроков / 44 задания**: структуры и классы; точные гарантии C++; контейнеры, файлы и ошибки.
- В developer-only English-черновике теперь **14 разделов / 54 урока / 248 заданий / 2437 из 2904 полей** (+443). Теория, условия/границы, подсказки, разборы, навыки и подписи выбора покрыты целиком для заявленных разделов.
- Сохранены различия между const и constexpr, initialization и assignment, синтаксическим успехом ввода и прикладным диапазоном, map[] и find, size и числом поступлений. Файловые задачи явно остаются упражнениями для внешней среды: codelib не запускает код и не создаёт файлы задания.
- Канонические ID, C++, ответы, fixtures, пользовательский прогресс и schema 1 не менялись.

## Локализуемые сообщения наград
- Категории используют **LocalizedStringResource в слое UI**, без зависимости LearningCore от SwiftUI.
- Скрытый заголовок и описания — явные Text-ветви, не динамический String с тернарным оператором. Названия и условия секретных наград не раскрываются до получения.
- Дата учёта старой награды и дата получения новой используют отдельные шаблоны. Баннер интерполирует название, а не склеивает переводимые фрагменты.
- Настоящее извлечение Xcode добавило **12 ключей**; Apple-каталог содержит **221/221** переведённых ключей и успешно скомпилирован `xcstringstool`. Сырые метаданные остаются вне Git/app.
- Определения наград по-прежнему отображаются на русском; системный язык не включает неполный English. Курс/каталог переводов остаются вне app bundle.

## Проверки совместимости
- Файловый round-trip расширен до **31 choice-задачи разделов 6–14**: ответы проверяются при preview/RU/preview без изменения JSON; сохраняются профиль/UUID/аватар, позиции, награды/даты, Unicode и пустые черновики, подсказки и unknown IDs.
- Новый UI-тест проверяет соответствие локализуемых категорий каноническим cases и прежним RU-подписям. Python проверяет новые ключи скрытых наград, дат и баннера в настоящем manifest, полноту каталога, placeholders и воспроизводимость.
- Полная регрессия успешна: **87 Swift-тестов, 8 Python-тестов, 300 C++-исходников / 1514 запусков, 306+14+18 UI-checks**. Packaged/Xcode Release 0.1.10/build11 запущены без stderr; отсутствие partial English и raw metadata проверено в обеих .app.
- После dry-run удалено 2,0 МиБ старых завершённых отчётов; последние два каждого вида, сборки/кеши/пользовательские данные сохранены. Подробности — `VERIFICATION.md`; внутренний UI smoke не заменяет внешний визуальный/VoiceOver/full-screen аудит.
