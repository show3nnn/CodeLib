# codelib 0.1.4 · Alpha

13 ноября 2026 · сборка 5.

## Новый учебный блок
**+1 раздел, +4 полноценных урока, +24 задания: 20 с написанием кода, 1 прогноз вывода, 3 объяснения.** Всего: **17 разделов, 64 урока, 296 задач** (199 код / 37 вывод / 60 объяснений).

Алгоритмический практикум:
1. Префиксные суммы, полуинтервалы, счётчики признаков, равновесные индексы и пакетные обновления разностями.
2. Фиксированные и переменные окна, максимальная/минимальная длина, подсчёт всех допустимых отрезков; контрпример для отрицательных элементов.
3. Два указателя: пара с заданной суммой, пересечение и слияние, подсчёт пар, окно без повторов и честная оценка стоимости map.
4. lower/upper bound, дубликаты, диапазоны значений и мини-проект поиска минимальной вместимости рейса.

В каждом уроке — теория, пример, инварианты/границы применимости, повторение, оригинальные задачи, две подсказки и разбор. Условия учитывают пустые массивы/отрезки, дубликаты, точное равенство порогам и отсутствие решения. Прежние 16 разделов и их поля не изменены.

## Функциональные улучшения
- Поиск программы курса теперь учитывает разделы, уроки, названия задач и навыки; несколько слов объединяются условием AND.
- Фильтры: все, не начаты, в работе, завершены. Есть пустое состояние и сброс поиска/фильтров.
- Позиция сохраняется отдельно для каждого урока, включая переход в другой урок и перезапуск. Для старых документов — безопасный fallback без сброса прогресса. Пустой черновик отличается от отсутствия черновика.

## Качество и порядок
- Общая логика поиска/фильтрации вынесена в независимое ядро, устранено дублирование условий списка/пустого состояния и проверки подписей переводов.
- Всем 20 новым code-задачам добавлены 200 developer-only случаев с независимыми переборными oracle. Вместимость проверена DP по границам дней, не вторым жадным алгоритмом. Эти случаи не раздувают интерфейс учебных примеров.
- `verify_content.py --section cpp.section.algorithm-lab` позволяет проверить один блок с отдельным отчётом.
- Удалено 1,9 МиБ старых диагностических прогонов после dry-run, сохранены последние два каждого вида. Данные пользователя, исходники, история и текущие сборки не удалялись.
