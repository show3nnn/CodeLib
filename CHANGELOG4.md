# codelib 0.1.3 · Alpha

13 ноября 2026 · сборка 4.

## Завершение прерванного этапа
- Незавершённая работа по локализации после `f1ceb33` сохранена и продолжена, проект не пересоздавался.
- Добавлен `CourseTranslation`: отдельный текстовый overlay с проверкой версии формата, ID курса, SHA256 исходного JSON, неизвестных/пустых/недостающих полей и готовности `reviewed`.
- Рабочий загрузчик не допускает неполный перевод. Разработческий preview отделён от загрузки приложения.
- Перевод вариантов ответа меняет только `choiceLabels`. Сохраняются прежние канонические значения, ID, исходники C++, ожидаемые ответы и fixtures; старый прогресс не мигрирует и не сбрасывается. Разбор показывает переведённую подпись, Picker сохраняет исходное значение.
- Подготовлен английский черновик первого урока и вводных заголовков: **52/2681 текстовых полей**, 1 из 60 уроков, 5 заданий. Авторский модуль и воспроизводимый JSON находятся вне app bundle.

## Чистота проекта для GitHub
- Добавлена проверка текущего индекса/неигнорируемых файлов на сборки, локальные данные, кеши и файлы больше 20 МиБ. Она входит в `verify.sh`, но не подменяет сканирование секретов и истории.
- Python-кеши и локальные `.env` игнорируются (`.env.example` разрешён).
- Добавлена осторожная очистка завершённых UI/launch-прогонов с сохранением двух последних каждого вида. По умолчанию dry-run, удаление только с `--apply`, без затрагивания исходников, `.local-data`, текущей `.app` и кешей сборки.
- Проверки генерации перевода и инструментов репозитория включены в общую регрессию.

## Проверки
Полная регрессия успешна: **63 Swift-теста + 2 Python-теста**, воспроизводимость курса/черновика, **275 C++-программ / 956 запусков**, **286+12+16 внутренних UI-checks**. Обе release-сборки запускаются без stderr; версия/сборка и отсутствие en-черновика в обеих `.app` проверены. Подробности и ограничения — PROJECT_PLAN.md / VERIFICATION.md.

После проверок новая очистка удалила **3,8 МиБ** устаревших завершённых прогонов, оставив два последних каждого вида. Пользовательские данные не затронуты.

## Что не заявляется завершённым
Полноценный English интерфейса/курса, перевод остальных 59 уроков, каталог/история/ошибки на английском и переключатель языка **не реализованы**. UI и рабочий курс остаются русскими, смешанный English не включён. Техническая валидация не заменяет содержательную рецензию перевода. Полная внешняя UI/VoiceOver/full-screen-приёмка остаётся заблокированной/непроверенной, как в предыдущем этапе.

Следующая задача: продолжить перевод курса и штатную Apple-локализацию интерфейса без смены ID; включать язык только после готовности полного комплекта. Версия увеличена последовательно с 0.1.2/build3 до 0.1.3/build4. Bundle ID, папка данных и schema 1 сохранены. Старые CHANGELOG и история Git не переписаны; push и GitHub Release не выполнялись.
