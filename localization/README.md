# Локализация курса

Это **разработческий черновик**, не доступная локализация приложения. Пока UI и весь рабочий курс на русском. В `drafts/course.en.json` переведены все текстовые поля первых 14 разделов: **2437 из 2904**, **54 урока / 248 заданий** и вводные заголовки. Осталось 10 уроков; качество полного английского курса не заявляется проверенным. В 0.1.10 исходный курс/fingerprint не менялся; расширены только переводы.

## Источники и проверка

- Авторские переводы: `scripts/content_en_01.py` … `scripts/content_en_14.py` (от первых программ до классов, точных гарантий C++, контейнеров/файлов/ошибок). Каждый объявляет SECTION_ID и SHA256 исходного `course.json`; изменение курса требует осмысленного пересмотра перевода. Helpers `translation_authoring.py` создают только текстовые поля, не C++/fixtures/ответы.
- `PYTHONDONTWRITEBYTECODE=1 python3 scripts/generate_localization.py` воспроизводит JSON.
- Та же команда с `--check` ничего не перезаписывает и проверяет воспроизводимость. Входит в `scripts/verify.sh`.
- `CourseTranslationTests` сверяет поля Python/Swift, защищённые данные и совместимость реального сохранения. `coverage(for:)` возвращает недостающие/неизвестные поля; `developerPreview(from:)` разрешён только для разработки.
- Генератор требует полного покрытия каждого заявленного раздела, отклоняет повторный ID/пустое поле/попытку изменить C++ и считает статистику из JSON. Python-тесты проверяют эти отказы и отсутствие непереведённой кириллицы в текстовых полях 14 текущих разделов; это не заменяет содержательную рецензию.
- Файловый round-trip разделов 6–14 проверяет все 31 choice-ответ, неизменность прогресса при RU/preview-проекции, UUID/имя/аватар, награды/их даты, позиции уроков, Unicode и пустой черновик, unknown IDs. Это developer preview ядра, не проверка переключателя языка в приложении.

## Контракт формата 1

`courseID`, `locale`, `sourceSHA256`, `status`, `texts`. Основные ключи строятся из стабильного ID сущности и роли поля (`cpp.first.theory`, `cpp.first.beacon.hint.1`). Номер подсказки обозначает её ступень, не позицию задания. Для вариантов и навыков ключ содержит SHA256 канонического значения, а не индекс в массиве.

Перевод не меняет ID, структуру/зависимости, исходники C++, ответы, числа, testCases или файловые fixtures. Для существующих choice-задач каноническим сохраняемым значением остаётся исходная строка: это сохраняет совместимость уже записанного прогресса. Переводится только `choiceLabels`; Picker сохраняет исходное значение, а разбор показывает локализованную подпись. Изменение самих канонических вариантов — изменение контента/совместимости, не задача перевода.

`apply(to:)` допускает только `reviewed` и полное покрытие **всех** текстов; пустые/лишние поля, устаревший SHA256 и неразличимые подписи вариантов отклоняются. Техническая полнота не доказывает корректность перевода: статус reviewed требует содержательной рецензии. Черновик не копируется в Resources и не включается в app bundle. `Course.bundled(locale: .english)` пока сообщает о недоступности, без русского fallback под видом английского.

## Native UI String Catalog

`ui/Localizable.xcstrings` — настоящий Apple String Catalog **вне app bundle**, переведены **221 из 221 автоматически извлечённых ключей**. Авторские значения: `scripts/ui_en.py`. PageHeader/Metric используют LocalizedStringResource; в 0.1.10 добавлены 12 ключей категорий/скрытых наград/дат/баннера. Категории объявлены в UI, не в LearningCore. Регистр eyebrow задаётся после локализации через Text.textCase; пользовательское имя и названия наград — параметры, не куски исходного ключа. Это не все UI-сообщения: динамические строки в AppModel/ядре, статусы/ошибки и ресурсы не становятся локализованными автоматически. При изменении UI число ключей изменится; проверка не разрешает оставлять новые ключи непереведёнными.

```sh
# Свежая сборка Xcode с SWIFT_EMIT_LOC_STRINGS, manifest, каталог, настоящий xcstringstool compile
bash scripts/extract_ui_localization.sh
# После редактирования только ui_en.py: воспроизвести каталог из прежнего актуального manifest
PYTHONDONTWRITEBYTECODE=1 python3 scripts/generate_ui_localization.py
# Без Xcode/перезаписи: проверить hash всех UI-исходников, ключи, placeholders и воспроизводимость
PYTHONDONTWRITEBYTECODE=1 python3 scripts/generate_ui_localization.py --check
```

`ui/extraction.json` фиксирует хеши исходников и относительные места использования, не абсолютные пути разработчика. Изменение UI требует повторного извлечения; нельзя вручную обновлять hash ради обхода проверки. Raw `.stringsdata` остаются в `.build`, игнорируются Git и запрещены проверкой публикации. Компиляция каталога выдаёт продукты только в `.build/localization-ui-check`; их нельзя копировать в app, пока English неполон. Placeholder-проверка сохраняет типы/формат `%lld`, `%@`, `%%` и других printf-подстановок, но не заменяет смысловую проверку переводов и будущих plural-вариаций.
