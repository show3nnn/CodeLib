# Локализация курса

Это **разработческий черновик**, не доступная локализация приложения. Пока UI и весь рабочий курс на русском. В `drafts/course.en.json` подготовлены **все 2904 текстовых поля, 17 разделов / 64 урока / 296 заданий** и вводные заголовки. Техническое покрытие полное, но статус остаётся **draft, не reviewed**: полнота не заменяет содержательную рецензию и готовность всего интерфейса. В 0.1.11 исходный курс/fingerprint не менялся; расширены только переводы.

## Источники и проверка

- Авторские переводы: `scripts/content_en_01.py` … `scripts/content_en_17.py` (все разделы, включая проекты, повторение и алгоритмический практикум). Каждый объявляет SECTION_ID и SHA256 исходного `course.json`; изменение курса требует осмысленного пересмотра перевода. Helpers `translation_authoring.py` создают только текстовые поля, не C++/fixtures/ответы.
- `PYTHONDONTWRITEBYTECODE=1 python3 scripts/generate_localization.py` воспроизводит JSON.
- Та же команда с `--check` ничего не перезаписывает и проверяет воспроизводимость. Входит в `scripts/verify.sh`.
- `CourseTranslationTests` сверяет поля Python/Swift, защищённые данные и совместимость реального сохранения. `coverage(for:)` возвращает недостающие/неизвестные поля; `developerPreview(from:)` разрешён только для разработки.
- Генератор требует полного покрытия каждого заявленного раздела, отклоняет повторный ID/пустое поле/попытку изменить C++ и считает статистику из JSON. Python-тесты убирают theory из каждого из 17 модулей по очереди и проверяют отказ; сверяют весь набор полей, отсутствие непереведённой кириллицы и статус draft. Это не заменяет содержательную рецензию.
- Файловый round-trip проверяет все **97 автоматических ответов (60 choice + 37 output)**, неизменность прогресса при RU/preview-проекции, UUID/имя/аватар, награды/их даты, позиции уроков, Unicode и пустой черновик, unknown IDs. Это developer preview ядра, не проверка переключателя языка в приложении.

## Контракт формата 1

`courseID`, `locale`, `sourceSHA256`, `status`, `texts`. Основные ключи строятся из стабильного ID сущности и роли поля (`cpp.first.theory`, `cpp.first.beacon.hint.1`). Номер подсказки обозначает её ступень, не позицию задания. Для вариантов и навыков ключ содержит SHA256 канонического значения, а не индекс в массиве.

Перевод не меняет ID, структуру/зависимости, исходники C++, ответы, числа, testCases или файловые fixtures. Для существующих choice-задач каноническим сохраняемым значением остаётся исходная строка: это сохраняет совместимость уже записанного прогресса. Переводится только `choiceLabels`; Picker сохраняет исходное значение, а разбор показывает локализованную подпись. Изменение самих канонических вариантов — изменение контента/совместимости, не задача перевода.

`apply(to:)` допускает только `reviewed` и полное покрытие **всех** текстов; пустые/лишние поля, устаревший SHA256 и неразличимые подписи вариантов отклоняются. Техническая полнота не доказывает корректность перевода: статус reviewed требует содержательной рецензии. Черновик не копируется в Resources и не включается в app bundle. `Course.bundled(locale: .english)` пока сообщает о недоступности, без русского fallback под видом английского.

## Native UI String Catalog

`ui/Localizable.xcstrings` — настоящий Apple String Catalog **вне app bundle**, переведены **303 из 303 автоматически извлечённых ключей**. Авторские значения: `scripts/ui_en.py`. В 0.1.14 добавлены 14 ключей системных summary/диагностики/native quit alert. `AppFailure` хранит причину и контекст, не готовый текст; `ErrorPresentation` использует типизированные core/фото-ошибки и native ресурсы. Вложенная причина форматируется тем же явным locale. Cocoa/POSIX ошибки классифицируются только по domain/code; неизвестные получают нейтральный summary. Исходная системная диагностика доступна отдельно, её язык не объявляется управляемым приложением.

PageHeader/Metric/категории/страницы/виды заданий/статусы/аватары тоже используют native ресурсы. UI-адаптеры не меняют core enum и сохраняемые значения. Регистр заголовков задаётся после локализации через Text.textCase; имя/ID/системная диагностика — параметры, не исходные ключи. Это не всё приложение: данные ресурсов, locale/plural, рецензия и внешняя приёмка ещё не готовы. При изменении UI число ключей изменится; проверка не разрешает оставлять новые ключи непереведёнными.

```sh
# Свежая сборка Xcode с SWIFT_EMIT_LOC_STRINGS, manifest, каталог, настоящий xcstringstool compile
bash scripts/extract_ui_localization.sh
# После редактирования только ui_en.py: воспроизвести каталог из прежнего актуального manifest
PYTHONDONTWRITEBYTECODE=1 python3 scripts/generate_ui_localization.py
# Без Xcode/перезаписи: проверить hash всех UI-исходников, ключи, placeholders и воспроизводимость
PYTHONDONTWRITEBYTECODE=1 python3 scripts/generate_ui_localization.py --check
```

`ui/extraction.json` фиксирует хеши исходников и относительные места использования, не абсолютные пути разработчика. Изменение UI требует повторного извлечения; нельзя вручную обновлять hash ради обхода проверки. Raw `.stringsdata` остаются в `.build`, игнорируются Git и запрещены проверкой публикации. Компиляция каталога выдаёт продукты только в `.build/localization-ui-check`; их нельзя копировать в app, пока English неполон. Placeholder-проверка сохраняет типы/формат `%lld`, `%@`, `%%` и других printf-подстановок, но не заменяет смысловую проверку переводов и будущих plural-вариаций.

## Каталог и история обновлений

`drafts/catalog.en.json` — **10/10 полей**, `drafts/releases.en.json` — **151/151 поле / 15 версий**. Это полные developer-only **draft**, не reviewed; они не включены в Resources/app. Авторские значения и два явно закреплённых source SHA256 находятся в `scripts/resources_en.py`.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/generate_resource_localization.py
PYTHONDONTWRITEBYTECODE=1 python3 scripts/generate_resource_localization.py --check
```

`ResourceTranslation` использует formatVersion/resource/locale/sourceSHA256/status/texts. Каталог: `catalog.<courseID>.title|summary`. История: `release.<numericVersion>.title|summary`, `release.<version>.feature.<featureID>.title|detail`. Для improvements/fixes ключ содержит SHA256 **канонической строки**, не индекс. Перестановка карточек и пунктов не меняет их переводы.

Перевод меняет только тексты. Доступность/язык/ID курсов, версия и формат ресурсов, версии/стадии/даты обновлений, ID функций/иконки и порядок сохраняются. Старой версии 0.1.0 не добавляются вымышленные stage/date. Дополнительно проверяется соответствие доступных курсов реальным course ID.

Production apply требует полного набора полей, актуального source и reviewed; даже developer preview требует целиком переведённого ресурса, без смешанного fallback. Bundled English пока сообщает о недоступности. Тесты reviewed используют явно синтетические экземпляры, не повышают статус файлов.

**При добавлении новой версии** сначала закончите реальные RU release notes, затем осмысленно обновите их перевод и source SHA256. Старые версии не переписывайте ради локализации; не подменяйте fingerprint автоматически для обхода проверки. Генератор проверяет все версии/feature IDs/элементы списков, защищённые поля и воспроизводимость; `--check` входит в verify.sh. `ResourceTranslationTests` подтверждает метаданные, перестановку списков и неизменность progress/lastViewedRelease/routing при проекции.

## Политика локали (0.1.14)

`PresentationLocale` — единая явная **ru**, пока не пользовательская настройка. Ею связаны сцены SwiftUI, передаваемые LocalizedStringResource, Gregorian-даты профиля/занятий/наград и percent. Часовой пояс остаётся местным; сохранённые Date и study-day keys не переформатируются. Исторические date-only ISO-строки release notes остаются каноническими. Native quit NSAlert форматируется через тот же resource helper; системные файловые панели не объявляются полностью управляемыми этой политикой.

Primary сообщения системных ошибок не зависят от localizedDescription. Отдельные Cocoa/POSIX пары domain/code отображают permission/missing/space/read-only/existing-file, Cocoa cancellation — отмену, остальные — общий ответ. Исходный Error/underlyingError не заменяется; непрозрачные domain/code/description показываются как данные в «Технических сведениях» или копируются по запросу. Никакой отправки. Это не универсальный перевод macOS diagnostics и не доказательство English-приёмки; plural-варианты и полноценный выбор языка ещё впереди.
