# Что остаётся после 186/186 UI-ключей

Сверка исходников 13.11.2026 для этапа 0.1.8. **Это рабочая инвентаризация, не доказательство полного покрытия интерфейса.** `extraction.json` описывает только строки, которые компилятор извлёк из текущих вызовов SwiftUI. Перевод всех этих ключей не делает приложение английским: каталог пока не включён в bundle, а динамические String не становятся LocalizedStringKey автоматически.

## Условия включения English

1. Завершить оставшиеся 32 урока / 1350 полей курса и провести содержательную рецензию полного перевода.
2. Заменить непокрытые динамические строки явными локализуемыми шаблонами. После изменений UI выполнить `bash scripts/extract_ui_localization.sh`; число 186 изменится, нельзя заморозить его ради зелёного теста.
3. Перевести новые ключи, core-сообщения и данные каталога/истории. Проверить placeholders, plural-варианты, даты и доступность, а не только отсутствие кириллицы.
4. Только после полной готовности подключить Apple-каталог к app и реальный выбор языка в onboarding/settings. Смена языка не должна перезаписывать черновики, ответы, UUID профиля, награды или позиции.
5. Пройти приложение целиком на RU/EN, включая ошибки, import/export, уведомления, меню, VoiceOver и маленькое окно. Проверки ядра с developer preview не заменяют эту приёмку.

Здесь намеренно нет флага «готово» по числу извлечённых ключей: неполный English не предлагается пользователю.
